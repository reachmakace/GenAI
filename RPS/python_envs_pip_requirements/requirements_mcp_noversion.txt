# ============================================
# INSTALLATION INSTRUCTIONS
# ============================================

# RECOMMENDED INSTALLATION APPROACH:
#
# 1. Create virtual environment:
#    python -m venv mcp_env
#    source mcp_env/bin/activate  # Linux/Mac
#    mcp_env\Scripts\activate     # Windows
#
# 2. Upgrade pip:
#    python -m pip install --upgrade pip
#
# 3. Install core packages first:
#    pip install mcp fastmcp anthropic openai nest-asyncio python-dotenv
#
# 4. Install remaining packages:
#    pip install -r requirements_mcp_noversion.txt
#
# 5. If conflicts occur:
#    - Install packages in smaller groups
#    - Use --no-deps flag for problematic packages
#    - Check package documentation for compatibility
#
# 6. For production, freeze versions:
#    pip freeze > requirements_locked.txt
#
# ALTERNATIVE: Install only what you need:
# pip install mcp fastmcp anthropic arxiv jupyter pandas requests

# BENEFITS OF NO VERSIONS:
# ✓ Always gets latest features and bug fixes
# ✓ Fewer dependency conflicts
# ✓ Easier maintenance
# ✓ Better compatibility with new Python versions
#
# CONSIDERATIONS:
# ⚠ Less reproducible across environments
# ⚠ Potential breaking changes
# ⚠ May need to test after updates
