Step 1: Setup your python environment in your local
    1. Make sure python is installed in your machine
    2. python -m venv <yourenv>
    3. cd <yourenv>\Scripts
    4. ./activate

Step 2: Set up the source code location  (Replace the path with your local path)
    1. $env:PYTHONPATH = 'D:\Makesh\Working\AI\RPS\Assignments\Capstone\cap-01'
    2. Set-Location -Path 'D:\Makesh\Working\AI\RPS\Assignments\Capstone\cap-01'

Step 3: Install the dependencies from requirement.txt
    1. pip install -r requirements.txt
    2. It will take some 5 - 7 mins. Wait for the installation to complete

Step 4: Run the ingestion pipeline script
    1. python -m ingestion.run_ingest --input_dir Data\Input --output_dir Data\Output
    2. Verify if the chunks.jsonl file created inside output folder

Step 5: Set up the OPEN API key
    1. $env:OPENAI_API_KEY = '<your API Key'

Step 6: Run the Rag pipeline
    1. python -m rag_pipeline.build_index --chunks Data\Output\chunks.jsonl --persist_dir .chromadb
    2. Verify .chromadb folder created in the root folder

Step 7: Running a sample query from command prompt
    1. python -m scripts.query_example
    2. Ensure there is output from the llm

Step 8: Running the streamlit UI
    1. streamlit run app\streamlit_app
